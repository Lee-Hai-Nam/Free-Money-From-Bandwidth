# Welcome to Free Money From Bandwidth! 👋

Hello there! Welcome to Free Money From Bandwidth, your new best friend for earning passive income with ease. If you've ever wanted to make money from your unused internet bandwidth but found managing all the different apps a bit of a hassle, you're in the right place!

This application provides a simple, clean, and unified dashboard to manage and monitor various bandwidth-sharing applications. Think of it as your central command center for passive income. 🚀

## What's Inside? ✨

- **📊 Unified Dashboard:** See all your earnings and stats from different apps in one beautiful screen.
- **🏪 App Store:** Easily discover and set up new bandwidth-sharing apps.
- **🐳 Container Management:** Start, stop, and check on your apps (running in Docker) with a single click.
- **🔒 Secure Credential Storage:** Your privacy is important. All your credentials are encrypted and stored securely on your local machine.
- **🌐 Proxy Configuration:** Configure and manage proxies to boost your earning potential.

## Build It Yourself 🛠️

For those who like to get their hands dirty, here’s how you can build the app from the source code:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Lee-Hai-Nam/Free-Money-From-Bandwidth.git
    cd Free-Money-From-Bandwidth
    ```

2.  **Install all the bits and pieces:**
    ```bash
    make install
    ```

3.  **Run in development mode (with live updates!):**
    ```bash
    make dev
    ```

4.  **Build the final production app:**
    ```bash
    make build
    ```
    You'll find the finished application in the `build/bin` directory.
