### For the Tech-Savvy (Prerequisites)

If you're planning to build the app from source, you'll need a few things first:

*   **Go:** Version 1.21 or higher
*   **Node.js:** Version 18 or higher
*   **Docker Desktop:** The latest version
*   **Wails v2 CLI:** You can find installation instructions [right here](https://wails.io/docs/gettingstarted/installation).

### Installation Guides

**Windows:**

1.  Download the `.exe` installer.
2.  Run it and follow the simple on-screen steps.
3.  Find Free Money From Bandwidth in your Start Menu and you're good to go!

**macOS:**

1.  Download the `.dmg` file.
2.  Open it and drag the app icon to your Applications folder.
3.  That's it! You'll find it in your Applications.

**Linux:**

1.  Download the `.AppImage` or `.deb` file.
2.  For `.AppImage`, make it executable (`chmod +x *.AppImage`) and run it.
3.  For `.deb`, install it with your package manager (`sudo dpkg -i *.deb`).
4.  Look for the app in your applications menu.

## Build It Yourself 🛠️

For those who like to get their hands dirty, here’s how you can build the app from the source code:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/[YOUR_USERNAME]/[YOUR_REPOSITORY].git
    cd [YOUR_REPOSITORY]
    ```

2.  **Install all the bits and pieces:**
    ```bash
    make install
    ```

3.  **Run in development mode (with live updates!):**
    ```bash
    make dev
    ```

4.  **Build the final production app:**
    ```bash
    make build
    ```
    You'll find the finished application in the `build/bin` directory.
