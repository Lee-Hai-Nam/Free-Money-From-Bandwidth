## Release v0.1.0

Welcome to the first release! This release lays the foundation for easily managing your bandwidth-sharing applications.

### Key Features

*   **Unified Dashboard:** Track earnings and statistics from all connected apps, providing a clear overview of your overall performance.

*   **App Store:** A centralized hub to discover and set up new bandwidth-sharing applications.

*   **Instance Management:** View and manage all your running app instances in one place.

*   **Proxy Configuration:** Manage and configure proxies for your bandwidth-sharing activities.

*   **Docker Integration:** Leverage the power of Docker for seamless containerization.

### Changes in this Release

*   **UI Improvement:** Streamlined the Settings page by removing the no longer needed 'General' tab.

### Known Issues

*   No known issues at this time.

### Future Plans

*   Support for more bandwidth-sharing applications.

*   Detailed statistics and historical data.

*   Further UI/UX enhancements for a more user-friendly experience.
